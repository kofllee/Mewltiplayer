# Settings & connection errors

Open settings from the world-sharing screen, `/mew settings`, or Mod Menu on Fabric (if installed).

## Share codes

| Mode | Behaviour |
| --- | --- |
| **New code every time** | Generate a new code each time (default) |
| **One code per world** | Each Minecraft world keeps its own reusable code |
| **One code across worlds** | Use the same reusable code for every Minecraft world |

**Reset code** replaces the selected invitation; **Reset all** clears saved invitations. Changing settings or resetting an active share may disconnect connected players. **Chat: ON / OFF** controls whether the code is displayed in chat after sharing starts.

Keep codes private, especially persistent ones. [Tailcat source and key handling](https://github.com/tailscale/tailcat).

## DERP

**Direct P2P** is a directly established route. **DERP** means encrypted traffic goes through a relay when a direct path is unavailable. A reported route may change, and **Checking** means it has not yet been confirmed.

- **DERP: Automatic** (recommended): Tailcat's default DERP map.
- **DERP: Custom URL:** load a DERP map from an HTTPS address.
- **DERP: Custom map:** paste a DERP map as JSON.
- **Preferred region:** choose a region; `0` selects automatically.

Custom settings can make a server unreachable or invalidate an old invitation. For technical background, see [Tailcat](https://github.com/tailscale/tailcat) and [Tailscale's DERP explanation](https://tailscale.com/kb/1232/derp-servers).

## Connection errors

These codes are generated by Mewltiplayer; Minecraft protocol errors may instead appear as normal Minecraft messages.

| Code | Meaning | What to check |
| --- | --- | --- |
| **M101** | Invalid share code | Copy the entire `tc...` code again. Ask the host for a new one if their invitation was reset. |
| **M201** | Could not reach host | The remote peer could not be reached or probed. Confirm the host is still sharing and try again, ideally without an interfering VPN. |
| **M202** | Tailcat helper failed to start | The bundled networking helper is unavailable or exited. Check security software/quarantine and whether the mod installed correctly; reinstall the matching build if needed. |
| **M203** | Connection timed out | The connection did not complete in time. Retry; if a VPN is active, test without it. Check whether the host remains online. |
| **M204** | Incompatible Tailcat protocol | The helper and its caller disagree on the protocol version. Ensure the installed mod and its bundled helper are from the same build. |
| **M299** | Connection failed | No specific error matched. Include the error text, Minecraft version and loader in a report, but remove any private codes. |
| **M301** | Failed to share world | Tailcat could not publish the world. Confirm the world is open to LAN and check for an interfering VPN or unavailable helper. |
| **M302** | Failed to reset share code | The saved code could not be reset. Retry after stopping sharing; check whether the game's configuration files are writable. |
| **M303** | Could not save this world's setting | The world-sharing preference could not be written. Check whether the world folder is writable. |

**VPN and latency:** Mewltiplayer does not require a VPN, and another VPN may route or block the helper's traffic. This can prevent Direct P2P, force DERP relay or stop the connection. Check `/mew status` and compare behaviour with the VPN disabled. DERP alone is not an error.

**Saved server says offline:** status checks use an actual network probe. Failure to retrieve status does not prove the server is permanently offline; try connecting again while the host is sharing.

For deeper networking behaviour, consult [Tailcat's documentation](https://github.com/tailscale/tailcat).
